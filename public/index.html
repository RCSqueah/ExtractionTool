② Add Expenses

📂 Add client documents

Drop the client's expense template (.xlsx), an Outlook email (.msg), chambers bill PDFs/scans (PNG/JPG), or a raw bank statement export (.csv) — any mix, any number. A bank statement CSV is read line-by-line and every transaction is added as a row: money out is coded as an expense, money in and anything that looks personal (drawings, transfers to yourself, personal card repayments, HMRC self-assessment, etc.) is added but excluded by default — always double-check these before exporting. Each file adds to the rows below rather than clearing what's already there, so a client who sends a separate file per month (e.g. three months of bank statements) can just have all of them dropped in together, or added one at a time as they arrive. Use "Clear all" above if you want to start over completely.
